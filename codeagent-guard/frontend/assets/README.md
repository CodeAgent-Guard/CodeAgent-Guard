# Frontend Assets

Place an optional `hero-loop.mp4` file in this directory to replace the CSS
fallback animation used by the dashboard hero.

Recommended video style:

- 15-30 second seamless loop
- no people, text, logos, lock icons, or keyboard footage
- low-saturation blue/teal/gray abstract information flow
- quiet enough to sit behind a translucent overlay

If `hero-loop.mp4` is absent, the dashboard automatically keeps the lightweight
CSS fallback background visible.
