# 信安赛作品要求实现状态

## 已实现

- 自研轻量 AI Agent 与外部 LLM。
- Agent、Tool Proxy、Policy Engine、Tool Executor、Audit 和 Dashboard 模块化。
- 文件读写、命令、HTTP 和邮件五类基础工具监管，另扩展五类工具。
- 每任务工具白名单与 `tool_not_allowed`。
- Allow、Ask、Deny 三级决策和用户审批恢复/拒绝闭环。
- ASK 时暂停 Agent，会在用户批准或拒绝后恢复原会话并生成最终回答。
- 工具链完成后由 Agent 二次生成自然语言执行总结，并对邮件排队等关键状态做事实校验。
- 路径穿越、敏感文件、危险命令、远程脚本、反弹 Shell、SSRF、密钥外传和外部收件人检测。
- 不可信 README、代码注释、日志、配置文件和工具输出样本。
- 调用时间线、风险告警、动态控制链路、参数详情和攻击复现摘要。
- Agent 历史任务侧列表与完整 Trace 回放。
- 审计页按 Trace 会话分组、会话筛选和完整本地日期时间展示。
- SQLite 审计记录与 SHA-256 前向哈希链。
- SQLite Trace 持久化，服务重启后仍可查看历史任务。
- 隔离数据库副本篡改实验。
- 100 条策略回归测试。
- 无防护 ASR、防护阻断率、FPR、平均延迟和 P95 延迟。
- 安全风险分析报告与实验评测报告。

## 当前边界

- OpenCode/MCP 属于第二阶段，本状态表不计入。
- `run_command` 已增加策略防绕过和资源限制，但不是容器或虚拟机级沙箱。
- SHA-256 哈希链可检测普通事后篡改；高保证部署还应增加 HMAC、数字签名或外部链头锚定。
- 待审批操作仍保存在进程内存中，服务重启后不能继续审批。
- Trace 历史最多保留 500 条，当前没有归档、导出和按用户隔离功能。
